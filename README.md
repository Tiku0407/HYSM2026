“अभय” हल्बा–हल्बी यूथ विकास एसोसिएशन एवं अखिल भारतीय हल्बा–हल्बी आदिवासी समाज, 36गढ़ केन्द्रीय महासभा, बालोद

## इस फ़ोल्डर में क्या है

| फ़ाइल | कहाँ लगेगी | काम |
|---|---|---|
| `index.html` | GitHub | पूरी वेबसाइट (फॉर्म, पुरस्कार स्थिति, आभार पट्टी, संपर्क) |
| `Code.gs` | Google Sheet → Apps Script | फॉर्म की प्रविष्टियाँ Sheet में सहेजती है |
| `README.md` | GitHub (वैकल्पिक) | यही निर्देश |

`index.html` में Google Sheet का Script लिंक पहले से जुड़ा है।

---

## भाग A – Google Sheet (एक बार)

1. Google Sheet खोलें → **Extensions → Apps Script**।
2. पुराना कोड मिटाकर `Code.gs` पूरा चिपकाएँ → **Save**।
3. Sheet नई/खाली हो तो ऊपर फ़ंक्शन सूची से **setup** चुनें → **▶ Run** → अनुमति दें।
4. **Deploy → Manage deployments → ✏️ (Edit)**
   - Execute as: **Me**
   - Who has access: **Anyone** (केवल *Anyone*, “Anyone with Google account” नहीं)
   - Version: **New version** → **Deploy**
5. जाँच: Script लिंक को इनकॉग्निटो विंडो में खोलें। `{"ok":true,"taken":{...}}` दिखे तो सही है। Google लॉग-इन पेज खुले तो चरण 4 दोबारा करें।

## भाग B – GitHub पर वेबसाइट

1. **github.com** पर लॉग-इन करें।
2. ऊपर दाईं ओर **+ → New repository**
   - नाम: `hysm2026` (अंग्रेज़ी, बिना स्पेस)
   - **Public** चुनें → **Create repository**
3. **uploading an existing file** (या Add file → Upload files) दबाएँ।
4. `index.html` (और चाहें तो `README.md`) डालें → **Commit changes**।
   - फ़ाइल का नाम ठीक `index.html` हो। `index (1).html`, `Index.html` नहीं चलेगा।
   - फ़ाइल किसी फ़ोल्डर के अंदर नहीं, सीधे मुख्य पेज पर हो।
5. **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, फ़ोल्डर: **/ (root)** → **Save**
6. 1–3 मिनट बाद (Actions टैब में हरा ✓ आने पर) इसी पेज पर लिंक दिखेगा:
   `https://<आपका-username>.github.io/hysm2026/`

## भाग C – अंतिम जाँच

- वेबसाइट मोबाइल पर खोलें। ऊपर **कुल पुरस्कार स्थान 77** और रिक्त स्थान की संख्या दिखे।
- पीली पट्टी में “पुरस्कार स्थिति लोड नहीं हो सकी” लिखा आए → भाग A का चरण 4 दोबारा करें।
- एक परीक्षण प्रविष्टि भरें → Sheet के “प्रविष्टियाँ” में पंक्ति आए → फिर उसे हटा दें, और “पुरस्कार स्थिति” में उस पुरस्कार का नाम (कॉलम E–G) खाली कर दें।

## बाद में बदलाव

- **बैंक विवरण:** `index.html` में `CONFIG` → `BANK` में भरें। खाली पंक्ति वेबसाइट पर नहीं दिखती।
- **संपर्क अधिकारी:** `index.html` में `CONTACTS` सूची।
- **आभार पट्टी के नाम:** `index.html` में `THANKS` सूची।
- बदलाव के बाद GitHub पर: पुरानी `index.html` खोलें → ⋯ → **Delete file** → Commit, फिर नई फ़ाइल अपलोड करें। (या ✏️ Edit से सीधे बदलें।) लिंक वही रहेगा।

## समिति के लिए (Google Sheet)

- **प्रविष्टियाँ:** हर फॉर्म की पूरी जानकारी। राशि मिलने पर अंतिम कॉलम में “हाँ” चुनें।
- **पुरस्कार स्थिति:** भरे हुए पुरस्कार हरे दिखते हैं। किसी पुरस्कार को फिर रिक्त करना हो तो उसकी पंक्ति में कॉलम E (सहयोगी का नाम) खाली करें।
- मोबाइल नंबर व पता केवल Sheet में रहते हैं, वेबसाइट पर नहीं दिखते।
